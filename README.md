# Media Management System

Web-based photo management platform developed as a collaborative university project focused on media organization, user interaction, and layered application architecture.

The application was designed with inspiration from the classic Facebook photo-sharing experience, aiming to create a simple and familiar user interface for browsing and managing images.

## Features

* User registration and authentication
* Public and private photo visibility controls
* Photo upload and album management
* Image gallery with hover effects
* Comment system for user interaction
* Search functionality for titles, tags, and descriptions
* Email notification module for photo comments
* Layered architecture separating presentation, business logic, and storage layers

## System Architecture

The application follows a layered architecture structure to improve modularity, maintainability, and scalability:

* Presentation Layer
* Business Logic Layer
* Storage Layer

## Technologies Used

* Node.js
* Express.js
* HTML/CSS
* MongoDB
* GitHub Collaboration Workflow

## UI & Design

* Grid-based gallery layout
* Thumbnail image previews
* Hover-based image interaction effects
* Old Facebook-inspired photo browsing experience
